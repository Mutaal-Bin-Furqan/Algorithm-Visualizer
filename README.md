# Algorithm Visualizer

An interactive visualization tool designed to demonstrate how common sorting and pathfinding algorithms work step-by-step.

## Features
- **Step-by-step element tracking:** Highlights individual bars or grid nodes in real time as the algorithm compares, swaps, or visits them
- **Color-coded state indicators:** Uses distinct colors to differentiate active comparisons, sorted elements, visited paths, and final routes
- **Smooth frame-by-frame transitions:** Renders each algorithmic operation sequentially so you can follow the exact logic without missing intermediate steps
- **Instant visual feedback:** Updates the canvas immediately when you trigger a run, pause, or reset the visualization

## Getting Started
1. Clone the repository: `git clone https://github.com/Mutaal-Bin-Furqan/Algorithm-Visualizer.git`
